AI와의 대화를 통해 많은 공부가 된다는 걸 느꼈다.
대화를 토대로 공부한 내용을 요약 정리해 둘 필요성이 있음을 느꼈다.

대화 내용을 요약해서 정리해서 파일로 저장하는 command를 하나 만들기로 했다. 

Gemini에게 어떻게 관련 command를 만들 것인지에 대해서 설명해야하는데, AI는 일반적으로 명령을 주면 바로 구현에 들어가는 경우가 많다.
이런 경우에는 충분히 내 구상을 전달하기에 무리가 있기 때문에, 내 요구사항이 충분히 정리된 이후에 해당 command를 구현하도록 먼저 설명을 했다.

AI에게 요구한 요구사항은 프롬프트는 초기에 3가지였다.
0. 대화를 토대로 공부한 내용을 요약할 필요가 있다.
1. 요구사항이 충분히 정리되어서 내가 구현을 요청하기 전까지는 먼저 구현하지 않을것
2. command 의 이름은 /summarize 로 해서, 대화 중 summarize 커맨드를 호출하면 이전까지의 대화내용을 요약해서 파일로 생성한다.

이렇게 세가지 사항을 먼저 정하고, 질문을 했다.

AI는 에 대해서 역질문했고,

     대화 중에 여러 주제가 섞여 있을 경우 어떻게 처리할까요?
